## Planned Assets

- `icons/` — Custom SVG icons or favicon files
- `images/` — Any background textures or illustration assets

## Current Status

The current v1.0.0-edu release uses emoji and CSS-only visuals,
so no external asset files are required.

All styling is handled via `css/style.css` using CSS custom properties
and no external dependencies (no CDN, no libraries).
